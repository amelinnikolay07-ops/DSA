# Префиксное дерево (Trie)

**Курсовая работа по дисциплине «Алгоритмы и структуры данных»**

**Текущий этап:** спроектирована структура Trie, реализованы основные операции и консольная демонстрация. Графический интерфейс и экспериментальное исследование будут разработаны позднее.

## 1. Цель и назначение

**Цель проекта** — разработать собственную структуру данных Trie на Python и применить её для хранения слов и поиска по префиксу.

Префиксное дерево хранит строки посимвольно: каждому переходу между узлами соответствует символ. Слова с одинаковыми начальными частями используют общие узлы.

**Где используется Trie:** автодополнение запросов, словари, поиск по началу слова, подсказки в редакторах кода.

В этой курсовой прикладной задачей является **автодополнение слов с сортировкой по частоте встречаемости**. Частота задаётся при добавлении слова и увеличивается при повторных вставках.

## 2. Устройство структуры данных

В файле `trie.py` реализованы два класса.

### `TrieNode` — узел дерева

| Поле | Назначение |
| --- | --- |
| `children` | Словарь вида «символ → дочерний узел» |
| `is_end` | Признак окончания сохранённого слова |
| `frequency` | Количество добавлений данного слова |

### `Trie` — дерево

Содержит корневой узел `root`, соответствующий пустому префиксу, и методы для операций над словами. Дочерние узлы хранятся в `dict`: переходы создаются только для встреченных символов.

**Пример.** Добавим слова `кот` (2), `котик` (5), `кошка` (3), `дом` (1):

```text
(корень)
├── к
│   └── о
│       ├── т  [слово, частота 2]
│       │   └── и
│       │       └── к  [слово, частота 5]
│       └── ш
│           └── к
│               └── а  [слово, частота 3]
└── д
    └── о
        └── м  [слово, частота 1]
```

Слова `кот` и `котик` используют общую ветвь `к → о → т`. Узел `т` обозначает конец слова `кот`, но при этом имеет потомка для слова `котик`.

## 3. Основные операции

**Вставка — `insert(word, count=1)`.** Программа проходит символы слова от корня. Отсутствующие переходы создаются; после последнего символа узел отмечается как конец слова, а частота увеличивается на `count`.

**Точный поиск — `search(word)`.** Программа проходит путь по символам и проверяет признак окончания слова. Например, если хранится `кот`, то `search("кот")` возвращает `True`, но `search("ко")` — `False`.

**Проверка префикса — `starts_with(prefix)`.** Проверяется только существование пути, поэтому `starts_with("ко")` возвращает `True`, если сохранено слово `кот`.

**Получение частоты — `get_frequency(word)`.** Возвращает частоту слова или `0`, если слово не сохранено.

**Автодополнение — `autocomplete(prefix, limit=5)`.** После перехода к узлу префикса программа обходит его поддерево в глубину (DFS), собирает слова и сортирует их по убыванию частоты; при равных частотах — по строке. По умолчанию возвращаются не более пяти подсказок.

**Путь поиска — `search_path(word)`.** Возвращает посещённые префиксы и признак успешного поиска. Этот метод пригодится для будущей подсветки узлов в графическом интерфейсе.

### Пример использования

```python
from trie import Trie

trie = Trie()
trie.insert("кот", 2)
trie.insert("котик", 5)
trie.insert("кошка", 3)

print(trie.search("кот"))       # True
print(trie.search("ко"))        # False
print(trie.starts_with("ко"))  # True
print(trie.autocomplete("ко"))  # [('котик', 5), ('кошка', 3), ('кот', 2)]
```

## 4. Свойства и сложность

Основные свойства Trie:

- Корень соответствует пустому префиксу.
- Из одного узла не бывает двух переходов по одному символу.
- Путь от корня однозначно определяет префикс.
- Терминальный узел обозначает конец сохранённого слова.
- Общие префиксы нескольких слов хранятся один раз.

При ожидаемом времени `O(1)` на переход по ключу словаря Python:

| Операция | Время |
| --- | --- |
| Вставка слова длины `L` | `O(L)` |
| Точный поиск слова длины `L` | `O(L)` |
| Проверка префикса длины `P` | `O(P)` |
| Автодополнение | Зависит от числа узлов поддерева, найденных слов и затрат на сортировку |

Количество узлов зависит от числа **различных префиксов** всех сохранённых слов. Общие префиксы уменьшают число узлов, но не гарантируют меньший расход памяти по сравнению с хеш-таблицей.
